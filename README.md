# The Isle Cheats (buyislecheats.com)

Static Astro site for The Isle Evrima overlays — ESP, visual options, and misc utilities — Cloudflare Workers ready.

SEO targets **the isle cheats**, **the isle esp**, **the isle cheats evrima**, and related PC keywords.

## Commands

- `npm run dev` — local dev server
- `npm run build` — production build + SEO/redirect verification
- `npm run generate:forums` — regenerate forum posts from `scripts/generate-isle-forums.mjs`
- `npm run prepare:media` — optimize screenshots into `public/media`

Set `SITE_URL=https://buyislecheats.com` when generating sitemaps for production.
