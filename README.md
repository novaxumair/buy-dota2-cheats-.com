# Wardogs Cheats (buywardogscheat.com)

Static Astro site for Wardogs cheats — aimbot, ESP, vehicle radar, wallhack-style visuals — Cloudflare Workers ready.

SEO targets **wardogs cheats**, **wardogs esp**, **wardogs aimbot**, and related PC keywords.

## Commands

- `npm run prepare:media` — compress attached screenshots into `public/media/wd-*`
- `npm run generate:forums` — regenerate forum posts and replies from `scripts/generate-wardogs-forums.mjs`
- `npm run build` — OG images, sitemap, Astro build, SEO verification
- `npm run dev` — local dev on port 5174

Set `SITE_URL=https://buywardogscheat.com` when generating sitemaps for production.
